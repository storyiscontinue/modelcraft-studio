ZERO-TRUST DATA BOUNDARY

绝对安全的隐私防线

在数学建模竞赛的极端保密规则下，我们制定了行业内极其硬性的网络数据出站检查机制：

🛡️ 底层 Socket 套接字域名审计

在所有外部链接与远程通信发起时，从系统网络底层捕获并自动审计非授权域名，任何未授权的数据请求和出站连接尝试均会被立即拦截。

🔒 微软 DPAPI 单独硬件加密

您配置的 API Key 绝对不会以明文保存在 `settings.json` 中。本软件强制调用当前 Windows 用户的硬件安全保护 API 进行隔离加密，防止物理拷贝窃取。

📦 一键 Sandbox 离线启动器

内置 Windows Sandbox 严格隔离环境脚本，一键封锁主机虚拟网卡、全局剪贴板、音视频输入及 vGPU 硬件驱动，建立彻底安全的纯离线算法验证空间。

⚡ 双 API 中转站物理隔离架构

工作流跑算接口与安全刺客审计接口物理隔离。低保密模型执行常规 Skills 求解，顶级推理模型专门校验主张证据链并进行严苛的盲审挑刺。
